# 3D Birthday Website Starter

A fast, mobile-first birthday microsite using HTML/CSS/JS + Three.js via CDN.

## Run
Open `index.html` with a local server. For example:

```bash
python -m http.server 5500
```

Then open http://localhost:5500

## Personalize first
1. Change `Her Name` in `index.html`.
2. Change `BIRTHDAY_DATE` in `script.js`.
3. Replace the three `.photo-placeholder` blocks with real photos.
4. Rewrite the message/signature.
5. Add a custom song later if needed.

## Deployment
This is static and can be deployed to Vercel, Netlify, GitHub Pages, or any static host.
